# 0.1.11 - Force full rerun

- A new **Chạy toàn bộ** job resets and processes every inventory row from position 1 to N.
- Website rows already marked **Hoàn thành** are no longer skipped in this mode.
- **Tiếp tục job đang dở** remains resume-only and does not restart rows completed by that job.
- Progress total always equals the full inventory count (for example 159/159).
