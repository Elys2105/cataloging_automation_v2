# 0.1.21 - Report header reconciliation

This release fixes recurring report-header failures observed in real browser runs.

## Rules

- The document number and symbol are selected from the report's own header crop.
  Cited documents in body prose cannot overwrite `Số ...-BC/...`.
- Normal report abstracts contain only the bounded title block after `BÁO CÁO`.
- A parenthetical date/period is kept only when it is visible inside that title block.
- Duplicate OCR crops and duplicate parenthetical dates are collapsed.
- Body prose beginning with a cited instrument is removed.
- A bounded parsed report title is authoritative over stale form data.
- Report title crops compare PaddleOCR and Vietnamese Tesseract independently.
- CPU OCR uses one thread to avoid the OpenMP warning and unstable oversubscription.

## Regression samples

Covered patterns include:

- `Tổng kết thực hiện Nghị quyết số 18-NQ/TW ... (khóa XII)`
- `Tổng kết công tác phòng, chống tham nhũng, lãng phí, tiêu cực nhiệm kỳ 2020 - 2025`
- duplicated `(Ngày ... tháng ... năm ...)`
- stale body text appended after the report title
- stale form values `CV/UBKTTU` or `KL/TW` while the PDF header is `BC/ĐU`
- missing first title line in a stale form value
