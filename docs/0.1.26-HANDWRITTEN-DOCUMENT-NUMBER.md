# 0.1.26 - Handwritten document number isolation

This release changes only the Công văn document-number recovery path.

- Adds two tight left-column crops around `So ...-CV/...`.
- Excludes the date column and most title text from handwritten-number OCR.
- Never stops focused header OCR before number crops are evaluated.
- Selects the number by agreement across crops/OCR engines instead of one high-confidence reading.
- Keeps abstract, type, date, author, submission and verification behavior unchanged.
