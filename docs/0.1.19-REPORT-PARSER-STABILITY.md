# 0.1.19 - Report parser stability

This release fixes the remaining Báo cáo title inconsistencies.

## Rules

- Normal reports never inherit the form date. A parenthetical date is part of the abstract only when it is visibly present in the PDF title block.
- Both `(Ngày 17 tháng 10 năm 2025)` and `(Kỳ báo cáo: ngày 13/10/2025)` are preserved when present.
- The form date may repair only the fixed landscape template `BÁO CÁO NGÀY ... VỀ CÔNG TÁC NỘI CHÍNH...`.
- Every raster `BC/...` record receives a dedicated high-resolution report-title pass once per OCR cache version.
- Dedicated crop OCR is prepended to generic OCR so the number, symbol, and report heading can correct stale form metadata.
- Candidate titles are bounded before comparison; the most complete bounded title wins.
- Generic `thực hiện ...` remains valid title text. It becomes a body boundary only when followed by a cited instrument such as Kế hoạch, Công văn, Quyết định, Nghị quyết, Chương trình, or Hướng dẫn.
- Identifier strings and stale garbage abstracts are never accepted as report titles.

## Regression coverage

The tests cover:

- no invented parenthetical date;
- visible textual and slash-form report periods;
- multi-line normal report titles;
- fixed landscape report recovery when the tiny date line is missing;
- stale wrong form type/symbol hints;
- old overlong or identifier abstracts;
- truncated crop selection.
