# 0.1.20 Report Runtime Fix

This release fixes runtime failures that unit-only report title tests did not cover:

- Detect Báo cáo from OCR even when stale form metadata says Công văn or Khác.
- Score all number/symbol candidates and reject cited body documents such as
  `Thực hiện Công văn số ...`.
- Preserve ordinary lowercase continuation lines in multi-line report titles.
- Never inject a form date into a normal report abstract.
- Allow form-date recovery only for the fixed table-style `BÁO CÁO NGÀY...`
  layout with independent table evidence.
- Invalidate old OCR caches and remove Python bytecode during patch install.
