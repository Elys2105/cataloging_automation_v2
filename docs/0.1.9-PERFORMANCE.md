# 0.1.9 - Performance without removing safety checks

- PaddleOCR is the primary pass. Tesseract runs only when Paddle quality is below configured thresholds.
- Tesseract runs one layout first and stops early when good; at most two variants by default.
- After the site is confirmed to expose only the viewer, later records skip repeated network/DOM waits.
- Viewer PNG is OCRed directly instead of being wrapped as PDF and rendered back to PNG.
- OCR output is cached by input SHA-256 for retries and reruns of the same unchanged image.
- Threshold and full-page OCR remain adaptive fallbacks, not unconditional passes.
